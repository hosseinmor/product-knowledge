# Templates

## Jira PRD

[`jira-prd.md`](jira-prd.md) defines the minimum structure for a Jira-ready
PRD. The PRD itself is not stored in this repository.

Product Knowledge authoring templates were removed because canonical Product
Knowledge is no longer authored here. JobVision authoring belongs with the
source behind <https://docs-jv.jvoffice.ir/>. Cando requires a separate
approved knowledge repository and internal site.

Design System templates remain under `shared/design-system/templates/` and are
governed by the Design System.
