# Shared Product Rules

Use this directory only for a rule or standard that is applied consistently across several products and has shared ownership.

Examples could include cross-product access, identity, organization, analytics, or content rules when their meaning is truly the same.

Prefer keeping rules inside the relevant Product Area or Shared Product Concept. Move a rule here only when duplication is creating inconsistency.

Do not use this directory for Design System behavior. Reusable UI rules belong under `shared/design-system/`.
