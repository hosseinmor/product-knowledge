# Shared Product Concepts

Use this directory only for business concepts whose definition, important data, lifecycle, or rules have the same meaning across more than one product.

Examples may include concepts such as Job Post, Organization, User Account, or Application, but create a document only after the shared meaning and owner are confirmed.

A Shared Product Concept does not replace product-specific Product Areas.

```text
Shared definition and rules
→ shared/product-concepts/{concept}.md

Product-specific behavior and flows
→ products/{product}/areas/{area}.md

Reusable UI behavior
→ shared/design-system/
```

Use `templates/shared-product-concept.md` when creating a document.
