# Shared Product Knowledge

This directory contains knowledge that applies consistently across multiple products.

A document belongs here only when:

- It is used by more than one product
- Its meaning is consistent across those products
- Its ownership is shared
- Product-specific exceptions do not change its core definition

Do not move a document here only to avoid duplication.

## Structure

```text
shared/
├── design-system/
├── content/
├── product-standards/
└── domains/
```
