# Product Variations

The shared Design System is the default. This section records intentional Product-level differences and shared Theme-context rules without duplicating the full system.

## Current guidance

- `theme-context.md` — canonical Product × Appearance Theme model, scope, ownership, and Foundation participation
- `brand-variants.md` — Product-specific Brand usage rules and examples
- `product-overrides.md` — scaffold for additional reviewed Product-specific exceptions when needed

Product business logic does not belong here. Runtime CSS/token implementation details belong in the relevant integration contracts.
