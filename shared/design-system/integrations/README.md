# Integrations

This directory records **live-source pointers, ownership, registration status, and integration gaps**. It should stay small and operational.

- `source-of-truth.md` — ownership, conflict, and live-source fallback rules
- `figma.md` — verified Figma file, Foundation collections, component identities, and design-source rules
- `code.md` — runtime implementation source registration and current Code gap
- `storybook.md` — executable Storybook source contract and current registration gap
- `component-mapping.md` — Figma component identity ↔ runtime component/prop ↔ Storybook mapping registry

Do not copy Figma, Storybook, or generated code documentation into this directory. Store stable pointers, ownership, mapping metadata, published/registered status, and known gaps only.
