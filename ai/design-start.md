# Design Start with AI

## Purpose

Help a designer use an approved Jira PRD, current Product Knowledge, and the shared Design System to create a useful first draft.

## Inputs

- Approved Jira PRD
- Product name
- Relevant Product Area documents
- Related shared Product Concepts or rules
- Relevant Design System documentation
- Optional Figma, research, data, or technical references

## Workflow

1. Read the PRD and identify the intended change.
2. Read the product `overview.md` and relevant Product Areas.
3. Read related shared Product Concepts and product rules.
4. Read the smallest relevant set of Design System foundations, tokens, components, patterns, accessibility guidance, and content guidance.
5. Prepare a concise design-context summary.
6. Identify missing or conflicting product information before drafting UI.
7. Create the requested first draft, such as:
   - user flow;
   - information architecture;
   - screen inventory;
   - state matrix;
   - wireframe or layout proposal;
   - component mapping;
   - interaction and copy draft.
8. Mark assumptions and unresolved decisions.
9. Suggest Product Knowledge updates when the work reveals missing or outdated context.

## Design-context summary

Cover:

```text
User and desired outcome
Current product behavior
Expected change
Rules and permissions
States and edge cases
Related Product Areas
Relevant Design System components and patterns
Missing information
```

AI output is a starting point. The designer owns interaction quality, visual hierarchy, coherence, and final design decisions.
